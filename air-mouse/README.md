# 📱 手機空中滑鼠 (Air Mouse)

用手機陀螺儀控制 Windows 電腦的游標。電腦跑 Python 伺服器（HTTPS + WebSocket，自簽憑證），手機用瀏覽器開網頁即可，不用裝 App。

## 快速開始（Windows）

1. 安裝 [Python 3.9+](https://www.python.org/downloads/)（安裝時勾選 **Add python.exe to PATH**）
2. 雙擊 **`start.bat`**：自動建立虛擬環境、安裝套件、啟動伺服器
3. 第一次執行時 Windows 防火牆會跳出視窗 → 勾選 **私人網路** → 允許
4. 視窗會顯示網址（例如 `https://192.168.1.23:8443`）和 QR Code，手機（同一個 Wi-Fi）用瀏覽器開啟
5. 出現「憑證不安全」警告：
   - Android Chrome：**進階 → 繼續前往**
   - iPhone Safari：**顯示詳細資訊 → 造訪此網站**
6. 按「開始」（iPhone 會詢問動作感測器權限 → 允許）

手動執行：
```bat
py -m pip install -r requirements.txt
py server.py                # 預設埠 8443
py server.py --port 9443    # 換埠
py server.py --dry-run      # 只印指令、不動滑鼠（測試用）
```

## 操作

| 動作 | 功能 |
|---|---|
| 轉動手機（左右 / 上下翹） | 移動游標 |
| 點螢幕左半邊 | 左鍵 |
| 點螢幕右半邊 | 右鍵 |
| 長按左半邊 | 按住左鍵（拖曳、選取），放開即放開 |
| 雙指上下 / 左右滑動 | 垂直 / 水平捲動 |
| ⏸ 暫停 | 暫停游標移動（可放下手機） |
| 🎯 校正 | 手機平放桌上，量測陀螺儀零點，消除漂移 |

預設握法：**螢幕朝上平放手上，上緣指向電腦**。也可在設定改成「直立」（像拿相機對著螢幕）。

## 設定（⚙，會自動記住）

- **靈敏度**：每轉 1 度移動多少像素
- **加速度**：慢轉精準、快轉移動遠
- **防抖：平滑**：低通濾波，越高越穩但稍有延遲
- **防抖：死區**：低於此轉速的手抖會被忽略（柔性死區，不會跳動）
- **點擊防抖時間**：手指按著時與放開後短暫凍結游標，點擊時游標不會偏掉
- **捲動速度**、**反轉左右 / 上下 / 捲動**、顯示感測器數值

另外還有自動漂移修正：手機幾乎靜止時會慢慢追蹤陀螺儀零點。

## 疑難排解

- **手機打不開網頁**：確認同一個 Wi-Fi（不是訪客網路）、防火牆已允許 Python（可在「Windows Defender 防火牆 → 允許應用程式通過」檢查）、網址是 `https://` 開頭。
- **顯示「沒有陀螺儀資料」**：必須用 HTTPS；iPhone 要在詢問時按允許（若誤按拒絕，關掉分頁重開）。
- **方向相反**：設定裡勾「反轉左右 / 上下」，或切換握持方式。
- **游標慢慢飄**：按 🎯 校正，或調高「死區」。
- **電腦 IP 變了**：重啟伺服器會自動重新產生憑證，手機需再接受一次警告。

## 檔案

- `server.py`：伺服器（aiohttp），Windows 用 Win32 API 控制滑鼠（`SetCursorPos` 不受指標加速影響，支援多螢幕與高 DPI）
- `static/index.html`：手機網頁（陀螺儀處理、防抖、觸控手勢都在這裡）
- `certs/`：自動產生的自簽憑證（已加入 .gitignore）
